# Birthday Gift Web

Personalized birthday mini-site built with Next.js App Router and ready for Vercel.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production check

```bash
npm run lint
npm run build
```

## Deploy to Vercel

Import this repository in Vercel. Vercel will detect Next.js automatically and use `npm run build`.

Optionally set `NEXT_PUBLIC_SITE_URL` to the final custom domain so social preview URLs always use that domain.
